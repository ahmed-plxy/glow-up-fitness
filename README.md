# Glow Up Fitness

واجهة React + Tailwind لمتابعة اللياقة والتحول الجسدي مع:
- BMR / TDEE calculator
- أهداف السعرات والماكروز
- Quick add meals
- LocalStorage persistence
- وزن يومي/أسبوعي مع Recharts
- تصميم Glassmorphism

## تشغيل محلي
```bash
npm install
npm run dev
```

## البناء
```bash
npm run build
```

## النشر على Vercel
ارفع المشروع كما هو إلى GitHub، ثم استورده في Vercel.
المشروع مُجهز ليُبنى تلقائيًا باستخدام Vite بدون أي تعديل إضافي.
